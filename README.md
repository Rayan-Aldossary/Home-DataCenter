# Home-DataCenter
Home data center on enterprise hardware: Cisco Catalyst 3850 L3 core &amp; access switches (10G EtherChannel), ISR 4331 edge router, OPNsense firewall with IDS, Dell PowerEdge R720 on Proxmox, Windows Server 2022 AD, DNS, DHCP, PKI, NPS &amp; WSUS, Docker with LibreNMS monitoring, and segmented VLANs for management, servers, users &amp; guests.
